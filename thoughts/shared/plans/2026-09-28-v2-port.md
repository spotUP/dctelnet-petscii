# Port onto v2.0-dev

The owner decided on 2026-09-28: "Port onto v2.0-dev now". Research is in `research/2026-09-28_v2-port.md`, which covers the renderer, prefs and inventory reports.

## Done means

- A new stack of branches `port/<topic>` starts from `upstream/v2.0-dev` (702ab0b). There is one branch per old PR, in the same order.
- Every branch builds with vbcc on both CPUs, clean under `-warnings-as-errors`.
- The host tests pass (`tests/`).
- The FS-UAE rig passes a reachability run of the features that need a machine.
- Old branches and PRs stay untouched.
- Replacing or retargeting the upstream PRs is the OWNER's decision at the end.

## Decisions

Implementation choices; the plan does not reopen them.

- **D1 Prefs growth.**
  - New fields go after `XferOptions`.
  - `LoadPrefs` changes for a v2 file whose `dataSize` differs from `sizeof`: it reads `min(dataSize, sizeof)` quietly, zeroes the rest, and `ValidateAndInitPrefs` defaults what is zero.
  - SavePrefs keeps writing `sizeof`.
  - This replaces the ext block, the reserved bytes and `PREFS_*_SIZE`.
  - It is its own first commit (port/prefs-growth), because Bruno's current code shows two requesters for any size change.
- **D2 Our fields on his struct**, all appended:
  - `UBYTE RedialTries, RedialDelay, AntiIdleMinutes, ConnectTimeout, Charset, Bell, AnsiMusic`, in his CamelCase field style;
  - `UBYTE Pad`, if the struct needs even length.
- **D3 One ANSI palette.**
  - His `AnsiColors[16]` (RGB4, SGR order) is the ANSI palette. Our `ansiRGB[16]` (24-bit) and `ansiMagic` are dropped.
  - 256-colour and RTG screens take the ANSI pens from `AnsiColors`, expanded to 32 bits.
  - The palette editor works in 16 steps per gun.
  - `DeviceColors` stays the ibmcon/console palette (≤16-colour screens).
  - This is a stated loss of 24-bit precision in the editor; it is listed under Found.
- **D4 Our flags** go into the free persistent State bits:
  - `APP_RLOGIN` 13, `APP_SSH` 14, `APP_WINDOW_SNAPSHOT` 16, `APP_VT_KEYS` 17, `APP_132_COLUMNS` 18.
  - `TELNET_DATA()` becomes `STATE_IS_NOT(APP_RAW_CONNECTION|APP_RLOGIN|APP_SSH)`.
- **D5 Renderer gating.**
  - Features that need ibmcon.device run only while `APP_RENDERER_IBMCON_DEVICE` is set:
    - READTEXT: selection, copy, Copy Screen, Save Screen;
    - GETMODES / DECCKM;
    - blink and iCE;
    - 132 Columns;
    - 256-colour ANSI pens;
    - font change in place.
  - Their menu items are disabled under other renderers, in `CreateAppMenus`, next to Bruno's Fast Scroll gating.
  - Our DSR answer (`dsr.c`) is skipped under the builtin renderer, which answers itself through `send_data` = `TCPSend`. TCPSend already routes SSH.
  - The default renderer stays Bruno's builtin one.
- **D6 Per-entry settings (site_prefs).**
  - Groups are rebuilt on the new field names:
    - Screen: FontName, FontSize, AnsiColors, DeviceColors.
    - Terminal: TelnetTermType, XemLibrary, Charset, and State bits PETSCII, RAW, LOCAL_ECHO, RLOGIN, SSH, plus the renderer bits `APP_RENDERER_ALL`.
    - Keyboard: BACKSPACE_DEL_SWAPPED, RETURN_SENDING_CRLF, VT_KEYS, plus F-keys.
    - Transfer: XferLibrary, XferOptions.
  - Geometry always comes from the live settings.
  - Site file:
    - `Sites/<id>.prefs` gets his header style: `DCTS`, version 1, dataSize.
    - Then groups, the PrefsStruct (its dataSize tolerated as in D1), fKeys and loginMacro.
  - Old DCS1-4 files (the owner's machine has DCS4) are converted:
    - `Prefs_FromLegacy(old bytes, len, &new)` is pure and host-tested, mapping every old field and flag.
    - The same converter replaces the essentials-only `ReadLegacyPrefs`, so an old `DCTelnet.Prefs` keeps its flags, paths and geometry.
- **D7 Porting unit.**
  - One squashed commit per old PR: `git diff prev..PR` applied with `git apply -3` onto the new branch, conflicts resolved once.
  - The commit message is the PR title, plus the PR description's summary.
  - The old per-commit history stays on the old branches.
- **D8 Menus:** our items go into Bruno's layout.
  - Terminal menu: Rlogin, SSH, VT Keys, Character Set (submenu), Bell (submenu), ANSI Music.
  - Display menu: 132 Columns.
  - DC Telnet menu: Capture to File, Save Screen.
  - Edit menu: ours (Copy Amiga-C, Paste Amiga-V, Copy Screen). Reset Screen moves to Z, as in our #40.
  - Connection menu: Connection Options.
- **D9 Tests:** `test/` becomes `tests/` (his rename). The check-fonts path is fixed to `../build/package/DCTelnet/Fonts/`.
