## Learnings

- **exec opens a device by path only if the file part equals the device's
  own name** (`BOOTX:ibmcon17.device` fails; `BOOTX:v17/ibmcon.device` works).
- **AmigaDOS `Seek()` returns the OLD position; MODE_OLDFILE is read+write;
  a string edit hook gets SGWork as object (A2)** -- three reviewer
  "bugs" that were wrong. Check claims against the autodocs before changing code.
- **True-colour screens**: recolouring a pen does not change drawn pixels;
  live recolour needs cybergraphics Read/WritePixelArray (done in #21).
- **`make` after `git commit` keeps the old BUILD_HASH**: `make clean` before
  installing, and check `strings | grep build` == HEAD.
- Rebase with the local `src/aos68k` edit needs `--autostash`.
- Own emulator rig: scratchpad `repro/` (copy of `nyhd2.hdf`, boot dir
  `s/startup-sequence` + `go`, local Python test servers on port 2323/79),
  launched with `open -g -n -a FS-UAE --args repro.fs-uae` so it never takes
  the owner's focus (once it did and the owner typed into it).
